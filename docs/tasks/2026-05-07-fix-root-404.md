## 📝 Notes & Discoveries

- The 404 occurred because Next.js couldn't find a page for the root path `/` and the middleware redirection was either not catching it or was bypassed by Turbopack's initial state.
- Adding a root `app/page.tsx` with a `redirect` is a robust way to handle the root path in i18n-heavy Next.js apps.
- Killing the stale dev server process (`taskkill /PID ... /F`) was necessary to ensure the new files were recognized by the Turbopack engine.
